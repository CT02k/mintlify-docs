Use a API da Wysepay para criar cobranças Pix, consultar transações e receber atualizações por webhook.

Todos os valores monetários usam centavos inteiros. Por exemplo, `1250` representa `R$ 12,50`.

## URL base

Defina a URL da sua API como variável de ambiente:

```bash
export WYSEPAY_API_URL="https://seu-dominio.com/api"
```

Para desenvolvimento local, use `http://localhost:3333/api`.

<Info>
As rotas em `/v1` são destinadas à integração de lojistas. Recursos administrativos e do dashboard não fazem parte da API pública.
</Info>
