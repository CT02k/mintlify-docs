## Pré-requisitos

Antes de começar, você precisa de:

- Uma conta Wysepay ativa.
- Uma API key criada no dashboard, em **Configurações > Chaves de API**.

<Warning>
Guarde a chave em variável de ambiente. Ela é exibida somente no momento da criação.
</Warning>

<Steps>
  <Step title="Defina a chave">
    ```bash
    export WYSEPAY_API_KEY="wyp_sua_chave"
    export WYSEPAY_API_URL="https://seu-dominio.com/api"
    ```
  </Step>
  <Step title="Crie a cobrança">
    ```bash
    curl --request POST "$WYSEPAY_API_URL/v1/charges/pix" \
      --header "Content-Type: application/json" \
      --header "x-api-key: $WYSEPAY_API_KEY" \
      --header "Idempotency-Key: pedido-1001" \
      --data '{
        "amountCents": 1250,
        "description": "Pedido #1001",
        "customer": {
          "name": "Maria Silva",
          "email": "maria@example.com",
          "phone": "11999999999",
          "documentType": "CPF",
          "document": "12345678901"
        }
      }'
    ```
  </Step>
  <Step title="Exiba o Pix">
    Use `copyPaste` como código Pix copia e cola ou gere um QR Code a partir de `qrCode`.
  </Step>
</Steps>

Confira a referência completa em [criar cobrança Pix](/api-reference/create-pix-charge).
